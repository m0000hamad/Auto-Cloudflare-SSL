## قدم بعدی

> نشست بعد دقیقاً از اینجا شروع کن.

**۱. ساختار ریپو را بساز** (فاز ۰)

```
backend/
  app/
    core/          # config, logging, errors, decimal helpers
    exchanges/
      base.py      # ExchangeClient ABC — قرارداد مشترک
      coinex/
      lbank/
    marketdata/    # ingest, normalize, candle store
    strategy/      # Strategy ABC + built-ins
    engine/        # live engine + backtest engine (کد استراتژی مشترک)
    execution/     # order router, paper broker, position state machine
    bots/
      base.py      # BotTransport ABC
      telegram/
      bale/
    api/           # FastAPI routers + WebSocket
    db/            # models, migrations (alembic)
  tests/
frontend/
docs/
```

**۲. `backend/app/core/config.py`** با pydantic-settings + `.env.example`
(بدون هیچ مقدار واقعی) — طبق خط قرمز شمارهٔ ۱ در SKILL.md.

**۳. اسکیمای اولیهٔ دیتابیس** روی Neon: جدول‌های
`exchanges`, `symbols`, `candles`, `strategies`, `strategy_runs`,
`signals`, `orders`, `positions`, `backtests`, `backtest_trades`,
`bot_users`, `audit_log`.
قبل از نوشتن، `references/architecture.md#data-model` را بخوان.

**۴. `backend/app/exchanges/base.py`** — تعریف `ExchangeClient` ABC.
این قرارداد قبل از نوشتن هر کلاینت واقعی باید قفل شود، وگرنه
CoinEx و LBank دو شکل متفاوت درمی‌آیند.

## تصمیمات قفل‌شده

تصمیماتی که گرفته شده‌اند و بدون دلیل جدید تغییر نمی‌کنند:

| # | تصمیم | دلیل |
|---|---|---|
| D1 | بک‌اند Python + FastAPI + asyncio | اکوسیستم تحلیل داده و اندیکاتور؛ WS همزمان چند صرافی |
| D2 | کلاینت صرافی اختصاصی، نه اتکای کامل به ccxt | امضای CoinEx و LBank خاص است؛ WS آن‌ها در ccxt ناقص/کند به‌روز می‌شود. ccxt فقط به‌عنوان مرجع تطبیق مجاز است |
| D3 | یک کلاس استراتژی، دو موتور اجرا (live/backtest) | جلوگیری از واگرایی منطق بین بک‌تست و لایو |
| D4 | `Decimal` برای همهٔ اعداد پولی | خطای شناور در حجم/قیمت غیرقابل‌قبول است |
| D5 | پیش‌فرض همهٔ محیط‌ها `paper` | ارسال سفارش واقعی باید تصمیم صریح کاربر باشد |
| D6 | تلگرام و بله پشت یک اینترفیس مشترک `BotTransport` | API بله عمداً سازگار با تلگرام است؛ کد دوباره نوشته نشود |
| D7 | PostgreSQL روی Neon به‌عنوان دیتابیس اصلی | کانکتور Neon از قبل وصل و فعال است |
| D8 | زبان گفتگو فارسی، زبان کد/کامیت انگلیسی | ترجیح کاربر + خوانایی کد |
